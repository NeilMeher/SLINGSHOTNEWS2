## 💡 TROUBLESHOOTING

**If `git clone` fails**:
- Download ZIP from: https://github.com/realasfngl/Grok-Api
- Extract to `C:\Users\neilm\OneDrive\Desktop\Grok-Api`
- Continue with Step 3

**If Python not found**:
- Download: https://www.python.org/downloads/
- Install Python 3.10+
- Check "Add Python to PATH"
- Restart terminal

**If `pip install` fails**:
```powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```
